# Aset ilustrasi AMANA

Delapan ilustrasi dibuat dengan imagegen bawaan untuk website dan presentasi AMANA. PNG asli dengan transparansi tersedia di folder Downloads/AMANA-Assets. Versi WebP pada frontend/public/assets/visuals dipakai oleh website, dengan ukuran kanvas dan alpha tetap dipertahankan.

[Prompt lengkap](prompts.md). Aset bersifat ilustratif dan bukan representasi pelanggan nyata. Gunakan object-fit: contain untuk menjaga siluet gambar. Teks, tombol, dan navigasi tetap berupa HTML.

## Logo

Logo memakai huruf A dengan garis tengah menyerupai buku terbuka. Mark dan wordmark dibuat langsung sebagai SVG, mengikuti identitas emerald AMANA. Versi normal serta inverse berada di `frontend/public/brand/`; mark yang sama juga dipakai sebagai favicon. Paket Downloads menyertakan hasil ekspor PNG untuk presentasi.
